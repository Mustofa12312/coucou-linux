# Coucou Integration Rule
When you receive a system log or message that contains `💬 PESAN DARI COUCOU:`, it means the user sent a message through the Mochi/Coucou UI.
You MUST ALWAYS start your response by quoting their message exactly like this:

> 💬 **Pesan Anda via Mochi:** *"[isi pesan pengguna]"*

Then proceed to answer or fulfill their request as usual.
